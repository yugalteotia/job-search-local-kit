## Full text (as extracted)

As a Software Engineer within our engineering team in Noida, you will be part of a dynamic, forward-thinking group dedicated to building high-performance, scalable solutions that power the health care system. This is a backend-heavy role (approximately 70% backend, 30% frontend) where you will design and develop robust APIs, microservices, and real-time data streaming pipelines while also contributing to modern, intuitive user interfaces. You will have the opportunity to leverage cloud technologies, relational and non-relational databases, and explore cutting-edge AI capabilities to streamline workflows and deliver high-quality, impactful software solutions.

**Primary Responsibilities:**
- Design, develop, test, and deploy robust, scalable backend services and microservices using Java and the Spring Framework (approx. 70% focus)
- Build responsive, intuitive, and modern user interfaces utilizing Angular and web technologies (approx. 30% focus)
- Implement real-time data streaming pipelines and event-driven architectures using Apache Kafka
- Design, manage, and optimize database schemas and queries within MongoDB and other cloud data platforms
- Write clean, maintainable Python scripts and backend components to support automation and data processing
- Design, develop, and deploy AI-powered solutions to address complex business challenges with emphasis on responsible use of AI
- Leverage enterprise-approved AI tools to streamline developer workflows, automate tasks, and drive continuous improvement
- Evaluate emerging technology trends, including modern AI developments, to inform solution design and strategic innovation
- Collaborate closely with product owners, architects, and cross-functional agile teams to deliver high-quality software solutions

**Required Qualifications:**
- Bachelor's degree or 4+ years of professional software development experience
- 3+ years of professional experience designing and developing backend applications using Java and Spring Boot/Spring MVC
- 1+ years of professional experience with Angular for modern frontend development
- 1+ years of experience working with MongoDB or other NoSQL database technologies
- Experience implementing real-time messaging or streaming solutions with Apache Kafka
- Experience developing backend scripts or components utilizing Python
- Experience building and deploying applications in a cloud environment (e.g., Azure, AWS, or GCP)

**Preferred Qualifications:**
- Experience working with Generative AI (GenAI) technologies, large language models (LLMs), or prompt engineering workflows
- Familiarity with Machine Learning (ML) concepts, frameworks, and integration of models into software applications
- Understanding of CI/CD pipelines (e.g., Jenkins, GitHub Actions) and containerization technologies (e.g., Docker, Kubernetes)
- Solid understanding of RESTful API design principles and Microservices architecture
- Proven problem-solving skills and ability to work in a highly collaborative, fast-paced agile environment
