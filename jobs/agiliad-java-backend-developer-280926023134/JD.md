Job description

Position Overview

Job Title: Java Backend Developer
Job Summary: We are looking for an experienced Java Backend Developer to build and support scalable server-side applications. You will write clean Java code, design RESTful APIs, and manage database integrations to ensure high performance and reliability. You will work closely with front-end developers, product managers, and system architects.

Key Responsibilities

Develop Services: Design, build, and maintain efficient, reusable, and reliable Java code for backend services.
Build APIs: Create secure and scalable RESTful or GraphQL APIs for web and mobile applications.
Manage Databases: Integrate and manage relational (MySQL, PostgreSQL, Oracle) and NoSQL (MongoDB) databases.
Optimize Performance: Identify bottlenecks, fix bugs, and optimize application speed and responsiveness.
Ensure Quality: Write unit and integration tests using tools like JUnit and participate in peer code reviews.
Collaborate: Work in an Agile/Scrum environment with cross-functional teams to deliver software features from concept to deployment.

Required Skills & Qualifications

Education: Bachelors degree in Computer Science, Engineering, or a related field.
Experience: 2 to 6 years of professional backend development experience using Java.
Core Technical Skills:
Proficiency in Core Java and Object-Oriented Programming (OOP).
Hands-on experience with frameworks like Spring Boot and Hibernate/JPA.
Strong knowledge of data structures, algorithms, and multithreading.
Experience designing and consuming RESTful web services.
Proficiency with SQL and relational database design.
DevOps & Tools: Familiarity with Git version control, Maven/Gradle build tools, and containerization tools like Docker or Kubernetes.
